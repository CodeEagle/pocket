## 可量化的目标

采样消融阶段记录：Local LOD 增加绘制批次，Native mip 在实际 Metal 的 DPR1/2 对照中更柔，两条生产实验分支已撤回。之后的有界人物片段 SSAA2 已进入普通 main Profile 候选，但 full20 稳定性未通过、模型 build P95 仍超门槛；像素/帧率不作为已解决。见[原生 mip 消融](VISUAL_NOVEL_NATIVE_MIP_ABLATION.md)、[子像素验收](VISUAL_NOVEL_RETINA_ACCEPTANCE.md)及[追踪表](VISUAL_NOVEL_GOAL_TRACKER.md)。

交付一个共用 Pocket JS 运行时、可在 Editor 编辑并构建的视觉小说 SDK，以及无需启动编辑后台就能玩的《雾港末班信》展示游戏。以现有对标矩阵的 **54 组能力及其全部子项**为功能基线；完成下表的故事、画质、编辑闭环、平台和性能门槛，并提供对应实际运行证据后，才可结束当前 Goal。

“集市场功能大成”以有边界的基线验收：[市场调研](VISUAL_NOVEL_RESEARCH.md)记录开源与商业产品，[54 组功能矩阵](VISUAL_NOVEL_LETSGAL_PARITY.md)保留每组内部缺口。新增需求需加入矩阵；不得通过删除缺口、合并统计或把不支持写成通过来达到 100%。
