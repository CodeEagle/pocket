# Authored music crossfade

## Source and scope

The retained parent `../pocketjs_flutter_demo/pocketjs_super_app_demo.html:923–953` implements a browser oscillator and mute toggle; `mini_apps/app_game_detail/main.js:1–50` provides the original game-detail entry. Neither contains a reusable asset-backed native crossfade. This increment adapts the existing Pocket VN timeline, audio gain sampler, intents, audio adapter and registered WAV player. Flutter receives the existing play/volume/stop transport; story policy and timing remain in JS.

The [official Ren'Py audio documentation](https://www.renpy.org/doc/html/audio.html) describes named channels assigned to mixers and multiplying relative volumes. It treats synchronized starts separately. That reference informs the capability boundary; this implementation does not claim sample-synchronized playback or feature equivalence.

## Contract and ablation

Named play instructions and timeline cues accept optional `group: "music" | "effects"`. The metadata travels through engine events/intents, checkpoints, rollback and the existing V4 save codec. It is optional for old stories and saves: omitted group retains the original rule, exact `music` uses music and ordinary custom channels use effects. The dedicated voice channel retains its existing ownership.

Explicit group requires a named play cue. Stop, unnamed cues, voice, `music-preview` and the four adapter-owned transient effect channels reject it. The canonical `music` channel cannot be assigned to effects. The shared schema check is reused by story, timeline, restore, save codec and Editor validation; malformed metadata rejects the update atomically. Sampling an envelope back to gain one retains its group.

The adapter computes `master × group × authored timeline gain`. Changing only group or gain updates volume without replay. Main and replay grouping is derived directly from existing intents and replay mappings. No additional group map, fade controller, timer, native mixer, instruction type or Dart state machine was added. Pending volume transport retains the existing latest-value coalescing. This removes the need for a separate crossfade subsystem; it is a structural ablation, not a measured performance improvement. The native eight-player budget remains unchanged.

The Editor exposes group selection in the instruction form, table and timeline cue rows. Unnamed channels display empty with a naming hint rather than a non-persisted default. Editing a channel recomputes the shared group/voice diagnostics without merging stale server errors; the existing Editor runtime explicitly exports the same reserved voice constant. Clearing the channel or switching to stop clears group in the same undo transaction. Invalid imported values remain diagnosable. Timeline gains use the existing curve editor, drag/history and save/build pipeline.
