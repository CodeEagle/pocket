技术说明：App 接入地址与 catalog

App 接入地址 是固定频道的签名 catalog（latest.json），记录主包和全部 mini app 的版本；mini app 不需要单独输入地址或密钥。

latest.json 是 App 运行时读取的签名更新清单；历史版本配置仅服务于对应版本，不是当前 App 接入地址。

Flutter 使用唯一 catalog 地址启动：flutter run --dart-define=POCKET_HOST_CONFIG_URL='<总入口URL>'；Mini app 使用 PocketAppConfig bootstrap。编辑器不会自动导入密钥。
